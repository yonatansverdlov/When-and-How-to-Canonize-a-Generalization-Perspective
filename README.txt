Two-version NeurIPS setup

Compile one of:
  - main_anonymous.tex      : anonymous NeurIPS submission + checklist
  - main_nonanonymous.tex   : non-anonymous preprint, with authors, no checklist

Shared manuscript:
  - paper_shared.tex

Important:
  - Keep the official NeurIPS 2026 checklist.tex in the project. It is input ONLY by main_anonymous.tex.
  - Author names/emails are stored ONLY in main_nonanonymous.tex, not in paper_shared.tex.
  - The non-anonymous wrapper currently uses the [preprint] option.
